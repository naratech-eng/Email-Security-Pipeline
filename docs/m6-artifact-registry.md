# M6 Artifact Registry

**S3 location:** `s3://email-security-pipeline-datasets/models/artifacts/registry.json`

Generated by `notebooks/M6/m6_t7_registry.ipynb`. M7 reads this at startup to resolve artifact S3 paths without hard-coding them.

## Schema

```json
{
  "version":   "m6",
  "created":   "YYYY-MM-DD",
  "splits":    "s3://.../datasets/processed/splits/",
  "artifacts": [ <ArtifactEntry>, ... ]
}
```

### ArtifactEntry

| Field | Type | Description |
|---|---|---|
| `name` | string | Artifact identifier used by `m6_inference.py` |
| `track` | `"email"` \| `"url"` | Which detection track this serves |
| `s3` | string | Full S3 URI to download the artifact |
| `sha256` | string \| null | SHA-256 of the file at upload time |
| `size_bytes` | int \| null | File size in bytes |
| `metrics` | object \| null | Test-set metrics from M6 training notebooks |
| `notes` | string | Architecture or usage note |

## Usage in M7

```python
import boto3, json

s3 = boto3.client('s3')
obj = s3.get_object(Bucket='email-security-pipeline-datasets',
                    Key='models/artifacts/registry.json')
registry = json.loads(obj['Body'].read())

for artifact in registry['artifacts']:
    print(artifact['name'], artifact['s3'])
```

## Loading order in `m6_inference.py`

1. Check `models/<file>` locally
2. If missing, `aws s3 cp <artifact.s3> models/<file>`
3. URL track: attempt Char-CNN first; fall back to RF if TF unavailable
