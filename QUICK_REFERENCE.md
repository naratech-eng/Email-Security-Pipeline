# Quick Reference: How to Run SVM Text Classification (M5-T1 Protocol)

## Super Quick Start

```
pip install -r requirements.txt
python 02_generate_data.py
python 03_train_svm.py
type results\m5_results.csv
```

Files:
- 02_generate_data.py: generate synthetic data
- 03_train_svm.py: train and evaluate models
- results/m5_results.csv: results log
